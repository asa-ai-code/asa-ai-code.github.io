# バドゥーギ卓 レーキ台帳

台帳ページのソースです。データは Firebase Realtime Database（`ledger`）に保存されます。

- GitHub Pages: https://asa-ai-code.github.io/rake/
- Firebase Hosting（旧URL）: https://badugi-3fc3a.web.app/

どちらのURLから開いても同じデータを読み書きします。

## Firebase Hosting に反映する場合

このフォルダで次を実行します。

```
firebase deploy --only hosting
```
